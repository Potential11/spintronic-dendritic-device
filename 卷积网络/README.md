# MNIST 三网络：仅训练1个epoch

仅包含 ratio3_preserve_sum 的第一轮训练及测试：FC、可训练卷积、固定输入权重树突网络。没有固定卷积比较，也没有20轮训练入口。

## 运行

需要 Python 3.10+，在本目录运行：

```bash
python3 -m pip install -r requirements.txt
python3 code/epoch1_batch_accuracy_ratio3.py
```

首次运行自动下载MNIST到 `data/`；CSV和图输出到 `results/epoch1_batch_accuracy_ratio3/`。再次运行会重新训练并覆盖同名结果。本程序保持原来的行为，不保存预训练权重。

## 训练和测试

- 60000张干净MNIST训练图像，训练1个epoch，batch size 512，共118个batch。
- 测试固定使用MNIST测试集前500张（索引0–499），三个网络使用相同的测试图像与噪声实现。
- 训练前测试一次，此后每3个batch测试一次；逐batch曲线最后一个采样点为117。第118个batch仍会训练，最终Gaussian噪声扫描在完整1轮结束后进行。
- AdamW，学习率0.001，weight decay 0.0001，seed 42，无学习率调度。
- Gaussian逐batch测试强度0、0.20、0.25；椒盐强度0、0.10、0.20；最终Gaussian扫描0至0.25，步长0.025。加噪后clip到[0,1]。
- 只在干净数据上训练，含噪图像用于测试。每个网络运行一次固定种子训练。

## 网络结构

| 网络 | 前端 | 分类头 | 可训练参数 |
|---|---|---|---:|
| FC | 输入标准化后展平784维 | 784→512→256→128→10 | 569226 |
| 可训练卷积 | 3×3卷积(1→24,padding=1)→BN→SiLU→2×2最大池化 | 4704→512→256→128→10 | 2576554 |
| 树突 | 3×3树突层(1→24,padding=1)→BN→SiLU→2×2最大池化 | 4704→512→256→128→10 | 2576410 |

每个分类隐藏层后接BN、SiLU，前两个另接Dropout(0.1)。输出10维logits，配合交叉熵。FC输入标准化为(x−0.1307)/0.3081；另外两种直接使用[0,1]像素。

树突3×3窗口按行分成三条分支。固定输入权重和分支偏置；分支读出权重、输出偏置、BN和分类头参与训练。三种ratio-3核各重复8次，卷积也以相同核初始化。

## 文件

`epoch1_batch_accuracy_ratio3.py`是唯一训练测试入口；其余四个Python文件仅提供网络、树突层和核变换定义，没有独立训练入口。保留原有数学计算与第一轮实验设置，只精简不需要的程序定义。包内不含数据集、历史结果或权重。验证范围见VALIDATION.md。
